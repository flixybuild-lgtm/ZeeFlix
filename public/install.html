QUESTIONS

FAQ

Is the APK safe to install?

The APK is built by GitHub Actions from this repository and each release includes a SHA-256 checksum. That does not replace an independent security review. Review the Android permissions and the included license notices before installing; Android also warns for apps installed outside the Play Store.

Why is it not on the Play Store?

The current Android build is distributed as a direct APK from the project’s GitHub Releases. The web app remains available separately. The Vega-derived Android source is licensed for noncommercial use only.

Does it cost anything or show ads?

There are no in-app ads or subscriptions in this build. The Android app requires noncommercial use under PolyForm Noncommercial 1.0.0. On builds configured with Firebase, usage and crash reporting is opt-in and off by default; provider and sync/cast services may receive requests when used. Read the included license and privacy notes before installing.

Which films are included?

Twelve titles from the Blender Foundation and Blender Studio open-movie collection, including Sintel, Tears of Steel, Big Buck Bunny, Spring, Cosmos Laundromat, Charge and Sprite Fright. Full credits are on the credits page.

Will there be an iPhone app?

Not yet — but the web app works in Safari and can be added to your home screen. An iOS build is on the roadmap.

Can I use my own movies?

The Android app exposes only VMovies from the Zenda-Cross catalog; it does not accept standalone video URLs as providers. The web app has a separate compatible-bridge setup.
